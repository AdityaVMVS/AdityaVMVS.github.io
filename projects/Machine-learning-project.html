Start here: what does learning mean?

A computer sees an image as numbers describing pixel colors, and text as a sequence of symbols. A neural network is a collection of adjustable calculations that turns those inputs into predictions. Training repeatedly compares a prediction with the correct answer and adjusts the network’s weights—the numbers it learns—to reduce its mistakes.

This coursework follows two connected ideas. In the combined Projects 1 and 2, the answer is an image label, such as “cat” or “airplane.” In Project 3, the answer is the next piece of text. Both use examples to learn patterns, but images need spatial structure while language needs ordered context.

Track A · Projects 1 + 2

From fully connected networks to a residual CNN: understand the image-classification challenge, improve training, and measure whether the model recognizes images outside its training set.

Track B · Project 3

Build the core parts of a Mini-GPT: convert text to tokens, use attention to read context, train next-token prediction, and generate new text.

Evidence note: the supplied Project 1 notebook is an unexecuted exercise scaffold, not a recorded training run. Its methods explain the foundations of the combined story; measured image results below come from the executed Project 2 notebook.

03

Projects 1 + 2: recognizing images

The challenge: tiny images, ten possible answers

The task is to classify CIFAR-10 images into airplane, automobile, bird, cat, deer, dog, frog, horse, ship, or truck. Each image has only 32 × 32 pixels and three color channels. There are 50,000 training images and 10,000 test images. Different objects can have similar colors, backgrounds can distract the model, and the same object can appear in different positions.

For example, recognizing a cat should depend on useful combinations of shapes and textures—not merely a patch of green grass that happens to appear behind cats in training. The challenge is to learn patterns that transfer to other images instead of memorizing the examples already seen.

What does accuracy measure?

Accuracy is the percentage of images assigned the correct label. With ten classes, uniform random guessing has an expected accuracy of 10%. Training accuracy measures performance on the examples used to update the model. Evaluation accuracy measures performance on a separate set. A high training score with a lower evaluation score is a warning that learning does not transfer perfectly.

Project 1: learn the foundations with an MLP

A multilayer perceptron, or MLP, is a fully connected network: each neuron combines outputs from the previous layer. Here the 32 × 32 × 3 image is flattened into a list of 3,072 numbers. The network can learn relationships between those numbers, but it does not explicitly preserve neighboring pixels or reuse the same local detector across the image.

The Project 1 challenge deliberately forbids convolutional layers. It starts with a poorly configured classifier and asks how far better optimization and regularization can take an MLP. Project 2’s introduction describes the typical preceding MLP ceiling as roughly 60–63%; this is course context, not a measured result from the supplied Project 1 notebook.

  • Fix the learning rate: the learning rate controls how large each weight update is. A step that is too large can make learning unstable; a smaller, appropriate step can make the loss decrease.
  • Add hidden layers and activations: hidden layers combine pixel information, and nonlinear functions such as ReLU let the model learn more than a single linear decision.
  • Compare losses and optimizers: a loss scores prediction errors. The exercises compare cross-entropy with hinge loss, and SGD, momentum, and Adam as different ways of updating weights.
  • Check backpropagation: compute how each weight contributes to an error, including a manual backward pass checked against PyTorch’s automatic gradients.
  • Initialize and normalize carefully: Xavier and Kaiming initialization set starting weight scales; batch normalization controls intermediate activation scales during training.
  • Reduce memorization: dropout temporarily removes some neuron outputs; weight decay discourages large weights; random crops and flips provide altered training examples.

These are the foundations explored in the exercise scaffold. It contains no saved execution results, so a personal starting accuracy or final MLP score cannot be established from that file.

Project 2: keep the image’s structure

A convolutional neural network, or CNN, looks at small patches instead of treating every pixel as an unrelated input. A learned filter slides across the image, using the same weights at every location. This lets a useful edge or texture detector respond in different parts of the picture. Later layers combine simpler features into more complex patterns.

The notebook begins by implementing convolution manually and checking it against PyTorch. It then trains a small CNN, visualizes its feature maps, compares ways to shrink those maps, studies normalization, and adds residual connections. This makes the final model a progression from understood building blocks rather than an unexplained accuracy number.

The final architecture

BestCNN starts with a 3 × 3 convolution producing 64 feature channels. Four residual stages expand the channels through 128, 256, 512, and 512 while reducing image resolution from 32 × 32 to 16 × 16, 8 × 8, and 4 × 4. Global average pooling summarizes each final feature map into one number, and a linear classifier produces ten class scores. The model has 9,549,898 trainable parameters.

A residual connection adds a block’s input to its processed output. Instead of rebuilding a representation from nothing at every block, the network can learn a refinement to what it already knows. These shortcuts help information and training gradients travel through the model; they do not guarantee that every deeper model performs better.

For example, if a mixed image contains 75% of an original cat image and a 25% patch from a dog image, CutMix trains against a corresponding mixture of the two labels. This encourages learning from partial visual evidence rather than relying on one distinctive patch. The actual label weights use the pasted area after clipping its boundaries.

Where did 98% appear?

The model crossed 98% training accuracy, not 98% evaluation accuracy. In the 30-epoch run, epoch 25 recorded 98.19% training accuracy and 91.58% evaluation accuracy. The 60-epoch run ended at 99.90% training accuracy and 93.23% evaluation accuracy. The best recorded evaluation result was 94.34% in the 80-epoch CutMix run.

Therefore, the supported story is “improved image recognition to 94.34% recorded evaluation accuracy,” not “achieved 98% on unseen images.” The high training score shows the model fits its learning examples well; the separate evaluation score is the more relevant measure of transfer.

Inspect what the network learned

Feature-map visualizations show the responses inside the CNN. Grad-CAM produces a heatmap of image regions that influence a chosen class score; the notebook applies it to the smaller CNN, not specifically to the final BestCNN. Comparing correct and incorrect predictions offers a way to inspect whether important regions overlap the object or distracting background, but a heatmap is not proof of human-like understanding.

Project 3: build a Mini-GPT

The idea: learn to predict what comes next

This task changes the output from an image label to the next piece of text. Given a passage, the model estimates which token should follow. Repeating that prediction—append a token, read the updated context, predict again—produces a longer passage. This is a small decoder-only Transformer trained on Shakespeare plays, not a general-purpose chatbot.

For example, given “The king hath,” the model produces probabilities for possible continuations rather than retrieving a fixed sentence. Sampling selects a continuation from those probabilities. The goal is to learn vocabulary, local phrasing, and dialogue structure from examples; plausible style is different from coherent reasoning or factual knowledge.

The challenge: numbers, context, and no cheating

The computer needs a numerical representation of text, a way to combine earlier context, and stable training. Crucially, it must not read the answer while predicting it. At generation time future tokens do not yet exist, so training must also prevent access to future positions.

The notebook provides data loading, model assembly, and training scaffolding. The implementation work fills in core components: byte-pair tokenization, normalization, attention, a gated feed-forward network, the Transformer block, cross-entropy loss, and sampling. “From scratch” here describes implementing these components within PyTorch—not writing an entire deep-learning framework or independently building all scaffolding.

Step 1: turn text into tokens

A token is a piece of text represented by an integer ID. Byte-pair encoding, or BPE, begins with the 256 possible byte values and repeatedly merges frequent neighboring pairs into larger pieces. Frequent text fragments can become single tokens, while less common words can remain several pieces. The trained vocabulary contains 1,000 tokens.

The corpus contains 1,115,394 characters. After tokenization, the notebook records 416,483 training tokens and 46,276 validation tokens in a 90/10 sequential split. Tests check that encoding and decoding preserve the text, IDs stay in range, and learned merges are applied consistently.

Step 2: represent identity and order

An embedding turns a token ID into a learned vector—a list of 192 numbers that the network can process. Learned positional embeddings add information about where the token occurs. This matters because the same words in different orders can express different meanings.

Each training example contains 128 input tokens. Its target sequence is shifted one position ahead: at each position, the network predicts the following token. It learns from many such prediction problems rather than from manually labeled answers to questions.

Step 3: use attention to read context

Attention allows each token position to combine information from earlier positions. Queries describe what a position is looking for, keys provide values to compare against those queries, and values carry the information to combine. The comparisons become normalized weights that determine how much each earlier position contributes.

Scaled dot-product attention divides comparison scores by the square root of the head dimension to keep their scale controlled. A causal mask blocks future positions before the probabilities are computed. Six attention heads perform these comparisons in parallel, giving the model several learned ways to combine context. This does not establish that a particular head learned grammar or another specific role.

Six Transformer blocks process the context, followed by final normalization and scores over the 1,000-token vocabulary. The complete model has 2,873,280 parameters. The feed-forward transform refines each position’s features; attention is the component that mixes information across positions.

Step 5: train and monitor errors

Cross-entropy loss penalizes assigning too little probability to the actual next token. A lower loss means the model gives better probabilities to observed continuations; it is not an image-classification accuracy percentage. The implementation uses log-softmax for numerical stability and passes checks against PyTorch’s reference loss.

  • AdamW: update model weights using adaptive optimization.
  • Warmup and cosine decay: begin with small learning-rate steps, increase them, then gradually reduce them according to the schedule.
  • Gradient clipping: limit excessively large gradient updates.
  • Early stopping: stop when the monitored validation loss fails to improve and restore the best checkpoint.

The saved run’s monitored validation loss decreased from 4.5343 at step 250 to 3.1400 at step 1,500. Training continued fitting the training data, but validation loss later worsened; early stopping triggered at step 2,250 and restored the 3.1400 checkpoint. A later evaluation over 30 validation batches reported 3.0968, a separate measurement rather than the identical checkpoint-selection metric.

Step 6: generate new text

Generation reads a prompt, predicts the next-token probabilities, samples one token, appends it, and repeats. Temperature controls how concentrated those probabilities are: lower values tend toward more predictable choices, while higher values allow more variation. Top-p sampling retains a set of likely tokens whose cumulative probability reaches a chosen threshold before sampling.

The notebook compares temperatures 0.3, 0.7, 1.0, and 1.4. Its samples show dialogue formatting and Shakespeare-like vocabulary, but also repetition, invented words, and sentences that do not fully make sense. These are visible limitations of this small trained model, not evidence of reliable language understanding.

What the experiments do—and do not—show

Attention heatmaps offer a way to inspect which preceding positions receive attention. Additional runs replace RMSNorm with LayerNorm, replace SwiGLU with ReLU, or remove the causal mask. These variants train from random initialization for only 300 steps, while the baseline has already undergone longer training. Their recorded losses are useful exploratory outputs, but do not prove that a particular component caused an improvement under equal conditions.

The no-mask variant also has access to future context, so it is not a valid causal generation comparison. Finally, the tokenizer was fitted to the full corpus before the split; validation text was therefore not completely isolated from preprocessing. A stronger evaluation would fit the tokenizer only on training text and compare variants using matched training budgets and repeated runs.
