Zynq FPGA Hardware/Software Co-Design with Custom AXI Peripheral

Demo video

Summary

This project explores hardware/software co-design on a Zynq SoC by integrating a custom AXI4-Lite peripheral with the ARM Cortex-A9 processing system. The goal is to expose FPGA-accelerated functions through a clean, low-latency interface to Linux userspace.[file:30]

The design uses memory-mapped I/O and PetaLinux kernel modules with character drivers to validate data flow across AXI interconnects and hardware registers. By offloading compute-intensive work to FPGA logic and partitioning responsibilities across hardware–software boundaries, the system achieves substantially lower execution latency compared to pure software on the Cortex-A9.[file:30]
