Page-fault handler

Virtual memory · simplifiedC
void page_fault(uintptr_t address) {
    page_t *page = lookup_page(address);
    frame_t *frame = alloc_frame();
    map_page(page, frame, PAGE_USER | PAGE_WRITE);
    invalidate_tlb(address);
}

The handler allocates and maps a physical frame only when a process first touches the virtual page.

What was validated

  • Page-table creation and TLB invalidation.
  • FIFO scheduling and process state transitions.
  • Blocking and wake-up around disk completion interrupts.
  • Concurrent workloads under repeated allocation and I/O.
