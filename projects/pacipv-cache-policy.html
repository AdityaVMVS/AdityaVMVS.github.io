Introduction

PACIPV investigates whether predicted reuse information can guide eviction more effectively than recency alone. The policy was integrated into a cycle-level simulator and compared using identical cache configurations and workload regions.

Victim selection

Replacement policy · simplifiedC++
int chooseVictim(const Set& set) {
    int victim = 0;
    for (int way = 1; way < set.ways(); ++way)
        if (predictReuse(set[way]) < predictReuse(set[victim]))
            victim = way;
    return victim;
}

The policy ranks candidates using predicted future value, then selects the line least likely to provide useful reuse.

Evaluation checklist

  • Use identical warm-up and measurement intervals.
  • Compare per-workload and geometric-mean results.
  • Track policy metadata overhead.
  • Inspect workloads where prediction underperforms recency.
