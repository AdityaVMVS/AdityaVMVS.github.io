Introduction

This project brings sensing, inference, and network telemetry together on a constrained microcontroller. FreeRTOS separates time-critical acquisition and inference from communication, while careful memory planning keeps execution predictable.

Inference task

FreeRTOS · inference loopC
for (;;) {
    xQueueReceive(sample_queue, &sample, portMAX_DELAY);
    preprocess(&sample, model_input);
    run_inference(model_input, output);
    xQueueSend(result_queue, output, 0);
}

Queues decouple timing-sensitive acquisition from inference and network activity.

Validation focus

  • Measure worst-case task execution time and stack usage.
  • Check model accuracy after quantization.
  • Stress telemetry without delaying acquisition.
  • Compare embedded output against the desktop reference.
